# 20260101特征工程优化工作总结

## 1. 前置阶段工作以及文件所处位置

* feature-engineering： 在data下面，是该阶段任务的数据以及输出目录
* `特征工程`为前缀的ipynb文件,原本放置在notebook下方，用于执行
    1. 增加分子表征（ChemBerta）、
    2. 根据permutation计算特征重要性，并且输出重要性（在temp文件夹中新增了计算mask_vector的内容）
    3. 特征工程验证：进行独立验证，检查不同特征工程的情况下会有什么结果
* `figures`文件夹中是`test.py`生成的独立验证以及交叉验证的实验结果，原本均在notebook下方


## 2. 不同文件的功能

* 所有Phase1文件均增加了ChemBerta分子表征，由于预训练模型的限制，只有384和0两种选择
* 1_2和1_3会根据处理后的npz数据生成Umap图和聚类分析结果

* Phase3_1会根据独立训练结果，在`feature/outputs/temp`下生成特征评分，结合该文件夹下的其他脚本可以得到mask.json
* Phase3_2为主要的验证脚本，进行独立验证，可以选择是否加入mask
* Phase3_3原本是想通过N折查看是否发生泄漏，但是这个文件现在用不上了

## 3. 关于数据集

数据集在Phase1_1上完成划分，可选的三种分子表征为Morgan，Avalon和ChemBerta

当前数据集情况： 4268数据集全部纳入训练集中，剩下的按照7：3的比例纳入数据集

* 检查数据泄露的手段包括：UMAP降维，聚类分析，直接比较，得到结论为：**测试集独立干净没有泄露**

## 4. 关于表征分析结果

* 首先有Phase1_1输出各种类型的表征数据
* Phase3_2是进行独立验证的主要代码内容
